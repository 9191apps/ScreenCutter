# ScreenCutter

菜单栏里的 macOS 区域截屏工具。用全局快捷键框选一块屏幕，再复制到剪贴板，或保存为 PNG。

## 环境

- macOS 14 或更高
- Xcode 16 或更高

用 Xcode 打开 `ScreenCutter.xcodeproj`，运行 scheme **ScreenCutter**。应用不显示 Dock 图标，菜单栏会出现裁剪图标。

第一次截屏时，系统会请求屏幕录制权限。若被拒绝，可在「系统设置 → 隐私与安全性 → 屏幕录制」中允许 ScreenCutter。

## 用法

- 菜单「截取区域」，或快捷键 **⇧⌘2**（可在菜单「更改快捷键」里换成别的组合）
- 菜单「截取整屏」截取光标所在的整块屏幕，默认快捷键 **⌥⇧3**，可以关掉
- 菜单「截取窗口」后，悬停高亮窗口，点击确认。默认快捷键 **⌥⇧4**，可以关掉。选区不会跨到另一块屏幕
- 操作条「标注」会先把选区截进内存，再画矩形、箭头、画笔或文字。画完的标注会保持选中：拖动移动，拖矩形手柄缩放，Delete 删除；⌘Z 撤销上一步（包括移动、缩放和删除）。复制和保存用的是这张图
- 选中标注后方向键微调 1 点，Shift+方向键微调 10 点
- 文字工具下点击是新建文字。要移动或删除已有文字，先用矩形、箭头或画笔工具点一下它
- 标注工具条和菜单「拷贝文字」用本机识别图中的文字。识别失败时截图还在
- 菜单「滚动长图」框定可见区域后纵向滚动拼接。没到底时仍复制已经拼上的部分，并说明没有滚到底
- 拖出矩形；按住 Shift 约束为正方形。按住空格再拖，可以平移当前选区
- 松开后出现操作条：复制（Return）、保存、取消（Esc 或点压暗区域）
- 松开后可以拖边、拖角或拖动整块选区。方向键移动 1 点，按住 Shift 移动 10 点
- 保存使用系统保存对话框，默认目录是桌面，文件名形如 `ScreenCutter 2026-10-23 22.45.01.png`
- 取消保存对话框后，选区和操作条还在，可以改成复制

新快捷键需要包含 ⌘、⌥ 或 ⌃。启动时会检查当前组合是否已被系统快捷键或其他应用的全局热键占用。有冲突时不注册该热键，菜单会说明原因，并提供「更改快捷键」。截屏仍可从「截取区域」开始。应用回到前台时会再检查一次，占用消失后自动重新绑定。

## 测试

单元/视图测试：

```sh
xcodebuild -project ScreenCutter.xcodeproj -scheme ScreenCutter -destination 'platform=macOS,arch=arm64' test
```

真实环境冒烟（可选，需要辅助功能/屏幕录制权限，会操作真实鼠标键盘，默认不进 CI）：

```sh
E2E=1 scripts/e2e/smoke.sh
```

覆盖范围、工具和发布前手工清单见 [docs/e2e.md](docs/e2e.md)。脚本在 `scripts/e2e/`，不参与 Xcode scheme 和 `xcodebuild test`。

## 代码怎么分

同一个 Xcode target，按职责放在子目录里。几何和快捷键冲突判断不依赖窗口，单测直接覆盖它们。

- `App`：菜单栏入口，以及通用提示框
- `Capture`：截屏状态、屏幕录制权限、ScreenCaptureKit 取图
- `Export`：剪贴板和保存对话框
- `Geometry`：像素对齐、显示器坐标、操作条位置
- `HotKey`：区域截屏快捷键的保存、注册，以及和系统符号热键、Carbon 热键的冲突判断
- `Overlay`：每块屏幕上的遮罩、拖选和操作条
- `Annotate`：冻结图片上的矩形、箭头、画笔和文字
- `Recognize`：本机文字识别
- `Scroll`：纵向滚动拼接。实现说明在 [docs/scrolling-capture.md](docs/scrolling-capture.md)

截屏进行中的状态放在 `CaptureSession`。遮罩只负责显示和把鼠标事件交回会话，不自己决定复制或保存。
