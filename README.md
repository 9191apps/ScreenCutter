# ScreenCutter

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

菜单栏里的 macOS 截屏与标注工具。用全局快捷键框选区域、窗口或整屏，标注后复制到剪贴板，或保存为 PNG。

## 功能

- 区域截屏、整屏截屏、窗口截屏
- 选区可拖动、拖边/拖角缩放；可调视野的像素放大镜、1px 微调、精确输入和边缘吸附
- 标注：矩形、箭头、画笔、文字；可选中、拖动、缩放（矩形）、删除和撤销
- 复制、保存，或在本机识别图中文字后拷贝
- 纵向滚动长图拼接；没滚到底时保留已拼接部分
- 菜单栏应用，不占 Dock；快捷键集中放在设置页，可改，冲突有提示
- 设置页管理快捷键、选区放大镜和屏幕录制权限

## 环境

- macOS 14 或更高
- Xcode 16 或更高

用 Xcode 打开 `ScreenCutter.xcodeproj`，运行 scheme **ScreenCutter**。应用不显示 Dock 图标，菜单栏会出现裁剪图标。

第一次截屏时，系统会请求屏幕录制权限；ScreenCutter 不再额外弹窗。若被拒绝，菜单顶部会出现「未开启屏幕录制权限」提示，点击即可打开「系统设置 → 隐私与安全性 → 屏幕录制」；「设置… → 通用」里也会显示权限状态。如果开关已经打开仍无法截屏，先关掉再打开，然后从菜单栏完全退出 ScreenCutter 并重新打开。

开发构建从本地 `Config/Signing.local.xcconfig` 读取 Apple Development 证书签名，授权可以跨重新编译保留；没有这个文件时会回退到 ad-hoc。配置方法见 [开发签名与屏幕录制授权](docs/signing.md)。

## 用法

### 截取

- 菜单「截取区域」，或快捷键 **⇧⌘2**（可在「设置… → 快捷键」里换成别的组合）
- 菜单「截取整屏」截取光标所在的整块屏幕，默认快捷键 **⌥⇧3**，可以在设置里关掉或更换
- 菜单「截取窗口」后，悬停高亮窗口，点击确认。默认快捷键 **⌥⇧4**，可以在设置里关掉或更换。选区不会跨到另一块屏幕

### 选区

- 拖出矩形；按住 Shift 约束为正方形。按住空格再拖，可以平移当前选区
- 拖动时出现放大镜：像素网格、光标所在像素为白色方块、蓝色粗十字定位，并显示显示器像素坐标和选区尺寸；松开后自动隐藏。「设置… → 通用」里可以关掉，也可以选择视野：紧凑（24 px，5×）、标准（40 px，4×）、宽阔（64 px，3×，默认）、超宽（96 px，2×）
- 边框、手柄和尺寸标签都画在选区外，不盖住被截的像素。小于 8pt 的选区不显示手柄，用键盘或「精确」调整
- 松开后出现操作条：复制（Return）、保存、精确、取消（Esc 或点压暗区域）
- 松开后可以拖边、拖角或拖动整块选区。方向键移动 1 像素，Shift+方向键移动 10 像素
- Option+方向键只调右边或上边：Option+→ 加宽，Option+← 收窄，Option+↑ 向上加高，Option+↓ 从上方收窄；加 Shift 每次 10 像素
- 「精确」打开像素输入面板：X、Y（显示器左上角起算）、W、H 都是整数像素；输入时实时预览，应用时夹紧到屏幕内，取消则回到原选区
- 拖动和缩放会吸附到屏幕边/中线以及窗口边缘；按住 Control 暂时关闭吸附，Shift 正方形时也不吸附
- 拖拽松手仍要求至少 4pt，避免误点产生小选区；操作条建立后可以缩到 1×1 像素
- 取消保存对话框后，选区和操作条还在，可以改成复制

### 标注

- 操作条「标注」会先把选区截进内存，再画矩形、箭头、画笔或文字
- 画完的标注会保持选中：拖动移动，拖矩形手柄缩放，Delete 删除；⌘Z 撤销上一步（包括移动、缩放和删除）
- 选中标注后方向键微调 1 点，Shift+方向键微调 10 点
- 文字工具下点击是新建文字。要移动或删除已有文字，先用矩形、箭头或画笔工具点一下它
- 标注工具条和菜单「拷贝文字」用本机识别图中的文字。识别失败时截图还在

### 复制与保存

- 复制写入 PNG 和 TIFF 到剪贴板；保存使用系统保存对话框，默认目录是桌面
- 文件名形如 `ScreenCutter 2026-10-23 22.45.01.png`
- 复制和保存用的是标注后的冻结图，不受桌面后续变化影响

### 滚动长图

- 菜单「滚动长图」框定可见区域后纵向滚动拼接
- 没到底时仍复制已经拼上的部分，并说明没有滚到底
- 实现说明见 [docs/scrolling-capture.md](docs/scrolling-capture.md)

### 设置

点菜单栏图标 →「设置…」（⌘,）。设置窗口有两个标签页：

- **通用**：开关选区放大镜并选择视野（紧凑/标准/宽阔/超宽）；查看屏幕录制权限状态，未开启时可以直接跳到系统设置
- **快捷键**：查看和更换区域、整屏、窗口三个快捷键；关掉整屏和窗口快捷键；恢复默认

### 快捷键

三个全局快捷键都可以在「设置… → 快捷键」里更换：点对应行的「更改…」，按下新组合。组合需要包含 ⌘、⌥ 或 ⌃；录入期间全局快捷键会暂停，避免按下旧组合时直接开始截屏。整屏和窗口快捷键可以关掉，关掉后仍可从菜单截取。

启动时会检查组合是否已被系统快捷键或其他应用占用。有冲突时不注册，菜单顶部会出现「…冲突，点此打开设置…」，点进去可以看到是哪一项。应用回到前台时会再检查一次，占用消失后自动重新绑定。

「全部恢复默认」把三个快捷键恢复为 ⇧⌘2、⌥⇧3、⌥⇧4，并重新打开整屏和窗口快捷键。

## 测试

单元/视图测试：

```sh
xcodebuild -project ScreenCutter.xcodeproj -scheme ScreenCutter \
  -destination 'platform=macOS,arch=arm64' \
  -derivedDataPath .build/DD4 \
  ENABLE_DEBUG_DYLIB=NO test
```

`ENABLE_DEBUG_DYLIB=NO` 是 Xcode 27 下 hosted test target 的绕行参数；不开时可能报重复产物或找不到 `ScreenCutter.debug.dylib`。

真实环境冒烟（可选，需要辅助功能/屏幕录制权限，会操作真实鼠标键盘，默认不进 CI）：

```sh
E2E=1 scripts/e2e/smoke.sh
```

覆盖范围、工具和发布前手工清单见 [docs/e2e.md](docs/e2e.md)。脚本在 `scripts/e2e/`，不参与 Xcode scheme 和 `xcodebuild test`。

## 代码怎么分

同一个 Xcode target，按职责放在子目录里。几何和快捷键冲突判断不依赖窗口，单测直接覆盖它们。

- `App`：菜单栏入口、设置窗口，以及通用提示框
- `Capture`：截屏状态、屏幕录制权限、ScreenCaptureKit 取图
- `Export`：剪贴板和保存对话框
- `Geometry`：显示器点/像素换算、整数像素选区、吸附候选、操作条和放大镜位置
- `HotKey`：三个快捷键的保存、注册，以及和系统符号热键、Carbon 热键的冲突判断
- `Overlay`：每块屏幕上的遮罩、拖选、放大镜、操作条和精确输入
- `Annotate`：冻结图片上的矩形、箭头、画笔和文字
- `Recognize`：本机文字识别
- `Scroll`：纵向滚动拼接。实现说明见 [docs/scrolling-capture.md](docs/scrolling-capture.md)

截屏进行中的状态放在 `CaptureSession`。遮罩只负责显示和把鼠标事件交回会话，不自己决定复制或保存。
